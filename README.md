# Інтеграція модуля штучного інтелекту у веб-застосунок

## Опис проєкту
Веб-застосунок для класифікації тональності відгуків і повідомлень (Sentiment Analysis) на базі моделі DistilBERT.

## Можливості
- Класифікація тональності тексту на позитивну (POSITIVE) та негативну (NEGATIVE).
- Візуалізація результатів у реальному часі (рівень впевненості моделі, кольорові бейджі).
- Історія запитів користувача в табличному форматі.

## Використані технології
- Python, Flask, Hugging Face Transformers, Bootstrap 5.
- CI/CD пайплайн на базі GitHub Actions.
